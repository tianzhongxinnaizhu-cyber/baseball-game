# Baseball GM v3.36

月単位で進める編成型・野球GMシミュレーションです。

GitHub Pages:
https://tianzhongxinnaizhu-cyber.github.io/baseball-game/

## v3.36
- 投手にも野手のサブポジションを付与
- 投手に野手守備用の「守備」「肩力」を追加
- 投手をDH・各守備位置のスタメン候補として起用可能
- 投手が野手起用された場合も通常の打撃成績・守備イニングを記録
- 野手出場中の投手が同じ試合でリリーフ登板しないよう二重出場を防止
- 投手の「野手能力」画面に守備位置・守備・肩力を表示
- 既存セーブの投手にも読み込み時に野手守備適性を自動付与
- 野手起用された投手も打撃タイトル・ベストナインの対象

ゲーム本体は `index.html` に直接配置しています。セーブはブラウザ内に保存されます。大切なデータはゲーム内のJSON書き出しでもバックアップしてください。
