# Baseball GM v3.37

月単位で進める編成型・野球GMシミュレーションです。

GitHub Pages:
https://tianzhongxinnaizhu-cyber.github.io/baseball-game/

## v3.37
- 二軍の投手を一軍へ上げる際、「投手としてベンチ入り」「野手としてベンチ入り」を選択可能
- 野手登録の投手は代打・守備交代候補に入り、ローテーション / ブルペンから外れる
- 投手登録の投手は従来どおりローテーション / ブルペンで運用
- 野手登録中の投手をベンチ野手・代打優先順位に表示
- 外国人一軍枠も選択した登録区分で投手 / 野手を判定
- 故障時の代替昇格でも登録区分を引き継ぐ

ゲーム本体は `index.html` に直接配置しています。セーブはブラウザ内に保存されます。大切なデータはゲーム内のJSON書き出しでもバックアップしてください。
